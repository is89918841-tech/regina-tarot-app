상담 메뉴를 선택하고 질문을 남겨주세요

자동화형 상품은 접수 후 결제 확인이 되면 자동 흐름으로 이어지고, 예약형 상품은 접수 후 일정 조율 안내가 따로 진행돼요.

현재 페이지는 접수페이지 먼저 만드는 구조에 맞춰 정리된 버전이에요. 여기서 상품이 자동화형인지 예약형인지 먼저 나누고, 이후에 자동 추천 / 보조앱 / 관리자 페이지 연결로 이어지게 됩니다.

접수 후 진행 방식

자동화형은 결제 확인 후 자동 흐름으로 이어지고, 예약형은 접수 후 일정 조율 안내가 들어가요.
