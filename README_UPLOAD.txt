레지나 helper용 data 패키지

사용법
1. 압축을 풉니다.
2. 안의 파일들을 전부 GitHub의 public/data 폴더에 업로드합니다.
3. 기존 consultation-products.json 같은 helper와 무관한 파일은 빼도 됩니다.
4. /data/manifest.json 이 브라우저에서 열리면 성공입니다.

포함 내용
- manifest.json
- 실사용 tarot/oracle/aux/iching/yukyo JSON
- decks (1).json 의 tarot_decks를 기준으로 누락된 타로 덱명을 manifest에 추가
- 누락 덱은 universal.json 기반으로 연결
